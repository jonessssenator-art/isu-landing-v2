# Второй вариант — главная страница ISU

Отдельный файл-макет, не связан с кодом первого сайта (01_SITE). Первый сайт никак не тронут.

## Как открыть
1. Открой файл `index.html` двойным кликом — он откроется в браузере.
2. Всё уже внутри: картинки в папке `assets`, стили и код — прямо в `index.html`. Ничего устанавливать не нужно.

## Что внутри
- Тёмный минималистичный стиль, крупные заголовки, анимации при скролле — по референсу capacity.so.
- Фон первого экрана — твоя иллюстрация горы (`пабаку иллюстрация.png` из Загрузок).
- Шапка и подвал сделаны по структуре первого сайта: слева/справа — навигация, в центре — лого, корзина — с рамкой слева. Шапка обычная (не «прилипающая»), поэтому больше не съезжает при скролле.
- Каталог из двух товарных карточек:
  - Протеин ISU — выбор вкуса (Шоколад/Ваниль/Клубника) переключает картинку, счётчик количества, кнопка «В корзину».
  - Креатин ISU — тубус ассорти (4 вкуса показаны как теги), счётчик количества, кнопка «В корзину».
- Настоящая рабочая корзина: значок с счётчиком в шапке → выезжает панель справа, можно менять количество, удалять товар, видно сумму. Корзина сохраняется в браузере (localStorage), переживает перезагрузку страницы.
- «Оформить заказ» — пока демо-кнопка: показывает пояснение, что оформление подключим, когда утвердим дизайн (реальной оплаты/заявки нет).
- Текст, товары и цены — реальные, взяты с текущего сайта isusport.ru (протеин 3 900 ₽, креатин 2 400 ₽, история горы Пабаку).

## Правки, второй круг
1. В шапке было два раза «Об ISU» — оставил один раз (в левом меню).
2. Убрал подсказку «Scroll» в углу первого экрана.
3. Блок «Характер / Дисциплина / Свой ритм» был растянут на всю ширину — собрал в компактную плитку из трёх колонок.
4. Фото горы Пабаку обрезало саму гору — теперь картинка вписывается целиком (не обрезается), а свободное место вокруг залито тёмным тоном под фон.
5. Карточки товара были огромные (фото во всю ширину карточки) — сделал фото меньше и по центру, с отступами вокруг, как аккуратное «фото на подложке». Сама карточка стала заметно компактнее.
6. Последний блок теперь называется «Начните с продукта ISU.»
7. Подвал сделал точь-в-точь по структуре первого сайта (лого + 5 ссылок: Продукция, Об ISU, Доставка, Поддержка, Дистрибьюторам) и добавил справа домен isusport.ru. Три ссылки (Доставка, Поддержка, Дистрибьюторам) — пока заглушки: на этих страницах на макете ещё ничего нет, добавим, когда дойдём до остального сайта.
